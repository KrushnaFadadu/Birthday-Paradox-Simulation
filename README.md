# Birthday-Paradox-Simulation
Python project demonstrating the Birthday Paradox using random simulations.

# Birthday Paradox Simulation

## About the Project
This is a Python simulation of the Birthday Paradox.

The Birthday Paradox demonstrates that in a group of people,
the probability of two people sharing the same birthday
can be surprisingly high.

## Technologies Used
- Python
- Random module
- Datetime module

## Features
- Generates random birthdays.
- Checks for matching birthdays.
- Runs 100,000 simulations.
- Calculates the probability of matching birthdays.

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python birthday_paradox.py
```
